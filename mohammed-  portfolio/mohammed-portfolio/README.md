# موقع محمد عبدالله الشعيبي الشخصي

موقع ثابت (HTML + CSS + JavaScript) بدون أي أدوات بناء. يشتغل على Vercel مباشرة.

## هيكل الملفات

```
index.html          الصفحة
styles.css          التصميم (الألوان والخطوط والوضع الليلي)
app.js              التشغيل (اللغتين، الفلاتر، النوافذ، المشغل الصوتي، نموذج التواصل)
data/projects.js    المشاريع  ← هنا تضيف مشاريعك الجديدة
data/site.js        بيانات التواصل، ذمة، سجل النتائج، المسار المهني، الخدمات، المنهجية، الشهادات، نصوص الواجهة
assets/             الصور والأصوات وملف نسخة العرض (assets/files)
data/sheet-demo.js  بيانات نسخة عرض نظام إدارة المحتوى (وهمية) التي يعرضها الموقع تفاعليًا
cv/                 ملفات السيرة الذاتية (PDF)
assets/certs/       صور الشهادات (webp) للعرض داخل الموقع، ونسخها الأصلية (pdf) للتحميل
```

## إضافة مشروع جديد

1. ضع صورة المشروع داخل `assets/` (يفضل webp بعرض 1400 بكسل تقريبًا).
2. افتح `data/projects.js`، انسخ أي مشروع كامل من `{` إلى `},` والصقه داخل القائمة.
3. عدّل الحقول: `id` و`title` و`summary` و`problem` و`solution` و`result` و`features`.
4. في `visual` استخدم: `{ type: "image", src: "assets/اسم-الصورة.webp", alt: { ar: "...", en: "..." } }`
5. حدد القطاعات في `sectors`، وحجم البطاقة في `size` (`"wide"` أو `"regular"`).
6. ارفع التعديل على GitHub، وسيظهر في الموقع خلال دقيقة.

ترتيب المشاريع في الموقع هو نفس ترتيبها في الملف.

## روابط القطاعات (للـQR)

كل رابط يفتح الصفحة مع جملة خاصة بالقطاع، ويعرض مشاريعه وحلوله أولًا:

- استشارات: `https://الدومين/?for=consulting`
- تقنية: `https://الدومين/?for=tech`
- النسخة الإنجليزية: أضف `&lang=en` (مثال: `?for=consulting&lang=en`)

## النشر على Vercel

1. أنشئ مستودعًا جديدًا على GitHub وارفع كل الملفات كما هي.
2. في Vercel: Add New → Project → اختر المستودع.
3. Framework Preset: **Other**، واترك أوامر البناء فارغة، ثم Deploy.
4. لربط دومينك: Settings → Domains → أضف الدومين واتبع تعليمات DNS.
5. بعد ربط الدومين، عدّل سطر `og:image` في `index.html` ليكون رابطًا كاملًا، مثل:
   `https://الدومين/assets/og.jpg` حتى تظهر صورتك عند مشاركة الرابط في واتساب ولينكدإن.

## تعديلات سريعة

- **بيانات التواصل**: أعلى ملف `data/site.js` (رقم الواتساب، الإيميل، لينكدإن).
- **السيرة الذاتية**: استبدل الملفات داخل `cv/` بنفس الأسماء.
- **نموذج الطلب**: يرسل الطلب جاهزًا إلى واتساب أو البريد، ولا يحتاج خادم.
- **ذمة**: موجودة كمشروع داخل `data/projects.js` (id: "dhimma"). لتبديل التصور التوضيحي بلقطة حقيقية، غيّر `visual` إلى `type: "image"`.
- **خارطة طريق ذمة**: عدّل `dhimma.roadmap` في `data/site.js`، وانقل `now: true` للمرحلة الحالية.
- **لوحة الدبلجة**: لتبديل الرسم التوضيحي بلقطة حقيقية، غيّر `visual` للمشروع إلى `type: "image"`.

## إضافة شهادة جديدة

1. حوّل الصفحة الأولى من الشهادة إلى صورة webp (عرض 1100 بكسل تقريبًا) وضعها في `assets/certs/`، وضع ملف PDF بجانبها.
2. في `data/site.js` داخل `certs` أضف سطرًا: الاسم والجهة والسنة، و`img` و`pdf`، و`url` إن كان للشهادة رابط تحقق.
3. شهادات الخبرة من جهات العمل تُضاف في `experienceDocs` بنفس الطريقة.
